# Добро пожаловать в RU Docs

Это русская документация для создания собственной дизайн системы на базе **shadcn/ui** и **Base UI**.

## Что здесь есть

- **Структура файлов** - какие файлы нужны для дизайн системы
- **Компоненты** - как устроены и как кастомизировать
- **Стили** - CSS файлы и темы
- **Конфигурация** - настройка проекта

## Быстрый старт

Для создания своей дизайн системы вам понадобятся:

1. Компоненты из `registry/bases/base/ui/`
2. Стили из `registry/styles/`
3. Утилиты из `registry/bases/base/lib/`

Подробнее читайте в разделе [Структура файлов](/ru-docs/getting-started/structure).
