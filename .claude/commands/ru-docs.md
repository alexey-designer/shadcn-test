# Создание статьи для RU Docs

Ты помощник по написанию русскоязычной документации для дизайн системы на базе shadcn/ui и Base UI.

## Инструкции

1. Если пользователь не указал тему статьи в аргументах (`$ARGUMENTS`), спроси его на какую тему написать статью

2. После получения темы:
   - Изучи существующую структуру в `apps/v4/content/ru-docs/`
   - Изучи релевантный код в репозитории для точности информации
   - Создай новый .mdx файл в подходящей папке

3. Формат статьи:
   ```mdx
   ---
   title: Название статьи
   description: Краткое описание
   ---

   # Заголовок

   Контент статьи на русском языке...
   ```

4. После создания файла:
   - Обнови соответствующий `meta.json` чтобы статья появилась в навигации
   - Сообщи пользователю путь к созданному файлу

## Аргументы

Тема статьи: $ARGUMENTS

## Структура ru-docs

Текущая структура:
- `apps/v4/content/ru-docs/` - корневая папка
- `apps/v4/content/ru-docs/getting-started/` - раздел "Начало работы"
  - `index.mdx` - Введение
  - `structure.mdx` - Структура файлов
